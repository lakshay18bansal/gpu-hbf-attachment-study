Generated by `tools/report.py` from `smoke`, `qproj`, `study`. GPU: 16-SM A100-profile slice (C2_legacy_paper: 8 SMs, as in the HBF-Sim paper) (`common/gpu/qwen3_slice.config`, 1410 MHz). Configurations: see `docs/02_design.md` and each folder README.

## 1. All runs

Slowdown is cycles / cycles of C1 on the same workload. HBM GB/s = Ramulator 32 B transactions (reads + writes) / time; HBF GB/s = GPU-requested HBF read bytes / time; % link = of the slice's HBF link bandwidth. Array amp. = NAND array reads x 4 KiB / requested bytes (1.0 = every byte read once); LHB hit = fraction of HBF requests served from the prefetch buffer. Latency = HBF request end to end (L2 exit to reply), core cycles (0.709 ns each).
